Hardware & driver compatibility

Tested on a ThinkPad P16 Gen 3 (2025, ELAN driver) — designed to work automatically on any recent ThinkPad using Lenovo's ELAN TrackPoint drivers, as well as older ThinkPads and external pointing-stick keyboards.

Automatic Setup

Recent ThinkPads (ELAN)

Most models from ~2022 onward — including X1 Carbon Gen 10+, T14 / T14s / T16 Gen 3+, P1 / P14s / P16s / P16, X13 Gen 3+, and current E/L series. NubMouse switches the driver's middle button automatically.

One-Time Toggle

Older ThinkPads (Synaptics)

Works on older Synaptics TrackPoint models (~2014–2021) too — simply set Middle Button Action to "Middle Click" once in your mouse / TrackPoint settings and NubMouse handles scrolling and clicking.

External Keyboards

TEX Shura & Firmware-Scroll Devices

Unlocks true middle-mouse dragging even on keyboards whose middle button is locked to firmware scrolling (like the TEX Shura / Shinobi M_FN) — with auto-recognition by USB ID and Raw Input filtering to leave regular mice untouched.

Frequently asked questions

Will NubMouse interfere with my external USB or Bluetooth mouse?

No! Open Settings → General → Devices (or the Devices submenu in the tray) and tick only your TrackPoint or pointing-stick keyboard. Any unticked external mouse keeps its completely native middle button.

Does it work with Blender, CAD, and 3D modeling apps?

Yes. You can configure one or more native-drag shortcuts (like holding Alt, Ctrl, Shift, or custom key combos) so pressing the middle button passes a real middle-button drag straight through to 3D viewports.

Does it work with external keyboards like the TEX Shura or ThinkPad TrackPoint Keyboard II?

Yes — any pointing-stick keyboard that sends a standard middle mouse button works with NubMouse, including the TEX Shura / Shinobi. On the Lenovo TrackPoint Keyboard II, turn off "ThinkPad Preferred Scrolling" in Lenovo's companion settings so it sends a plain middle button.

Why doesn't scrolling work in Task Manager or an elevated terminal?

Windows blocks normal apps from sending input to administrator windows. Tick Run as administrator in NubMouse's Startup settings once — it sets up a scheduled task so NubMouse starts elevated cleanly without a UAC prompt at every logon.

Is it safe? Does it read my keyboard?

NubMouse never installs a keyboard hook and never logs keys or window titles. It only checks GetAsyncKeyState for the specific native-drag shortcut key(s) you configure (and briefly while recording a custom shortcut in Settings), and makes zero network requests unless you turn on update checks.

How do I uninstall it?

Uninstall normally from Windows Settings → Apps → Installed apps → NubMouse, or run NubMouse.exe --uninstall. It cleanly removes the app, shortcut, startup entry, and settings (and restores your ELAN driver's Scrolling setting if it switched it).
