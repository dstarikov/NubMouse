Frequently asked questions

Everything about ThinkPads, TPMiddle parity, TEX keyboards, 3D/CAD drag, and privacy.

ThinkPadHow does NubMouse compare to Linux TrackPoint scrolling and classic TPMiddle?

On Linux (libinput / X11 / Wayland), TrackPoints still work this way by default to this day: tap the middle button to middle-click (open links in background tabs, close tabs), or hold it and push the TrackPoint to scroll. On Windows, ThinkPad drivers have historically forced a choice between either Scrolling or Middle Click — older Synaptics ThinkPads relied on the classic TPMiddle utility to get both, which stopped working cleanly when newer ThinkPads moved to ELAN and HID drivers.

NubMouse brings that exact out-of-the-box Linux / TPMiddle feel to modern Windows 10 & 11 ThinkPads using standard mouse-wheel events, switches ELAN's Middle Button Action automatically, and adds smooth scrolling, adaptive axis switching, instant autoscroll cancelling, per-device profiles, and optional 3D/CAD middle-drag.

3D & CADHow does direct middle-drag passthrough work in Blender & CAD apps?

3D and CAD apps (Blender, Fusion, SolidWorks, Rhino, FreeCAD, Maya) orbit and pan viewports by holding and dragging the middle mouse button.

  • ThinkPads / non-TEX TrackPoints: Native drag is disabled by default so your modifier keys stay free. Pick a quick key (Alt, Ctrl, Shift), combo (Ctrl+Alt, Alt+Shift, Ctrl+Shift), or custom shortcut under Settings → Scroll & click → Native drag. Holding that shortcut while pressing the middle button passes a real middle-button drag straight through.
  • TEX Shura / Shinobi: Enabled by default with Ctrl+Alt + moving the nub (no middle button needed) for smooth 360° viewport dragging.

Note on modifier keys: Because NubMouse never installs a keyboard hook, Ctrl, Alt, and Shift are still seen by the 3D app (for example, Blender maps Shift+MMB to Pan and Ctrl+MMB to Zoom). For unmodified middle-drag like Blender Orbit, either enable the app's built-in Emulate 3 Button Mouse mode, or record an unused non-modifier key (such as CapsLock).

TEX ShuraHow does NubMouse work with TEX Shura / Shinobi (USB & Bluetooth)?

On TEX keyboards, the middle button (M_FN) scrolls directly in firmware and can't be rebound to a holdable middle-button press (DIP 4 ON = tap middle-click + axis-locked firmware scroll; DIP 4 OFF = scroll-only).

NubMouse auto-detects the TEX Shura over both USB (04D9:0532) and Bluetooth LE (04D9:2521), plus the TEX Shinobi (04D9:0407), and defaults them to 3D drag only: middle-button takeover stays off so hardware M_FN scrolling works natively, while Drag without middle button (Ctrl+Alt + move nub) gives smooth 360° middle-mouse dragging without firmware axis locking. An optional Advanced: convert firmware scroll to drag mode is also included if you prefer M_FN + a hotkey.

Multi-DeviceCan I use a ThinkPad TrackPoint, TEX Shura, and external mouse together?

Yes! NubMouse uses Windows Raw Input to identify every pointing device in real time. Open Settings → General → Devices (or click Device setup wizard…) and wiggle each device to see it light up live:

  • ThinkPad TrackPoint → Full NubMouse (scrolling + middle-click + optional drag shortcut)
  • TEX Shura / Shinobi → 3D drag only (native M_FN scrolling + Ctrl+Alt 360° drag)
  • External USB / Bluetooth mouse → Ignore (native) (completely untouched)

You can also open Scroll & click → Configuring to customize speed, axis lock, indicator, or shortcuts per device — and the live Test pad always shows which input device is active.

HardwareWhat other pointing-stick hardware is supported?

Any pointing device that sends standard Windows mouse input works — including modern ELAN ThinkPads (automatic driver switching), older Synaptics ThinkPads (one-time "Middle Click" toggle), Lenovo TrackPoint Keyboard II (turn off "ThinkPad Preferred Scrolling" in Lenovo's companion app), Dell TrackStick / HP PointStick laptops, and custom QMK / ZMK pointing-stick keyboards. For any unrecognized device, run the Device setup wizard, wiggle it, and pick its mode.

WindowsWhy doesn't scrolling work in Task Manager or an elevated terminal?

Windows blocks non-elevated apps from sending input to administrator windows. Tick Run as administrator in NubMouse's Startup settings once — it creates a scheduled task so NubMouse starts elevated cleanly without a UAC prompt at every logon.

PrivacyIs it safe? Does it read my keyboard or phone home?

NubMouse never installs a keyboard hook and never logs keys or window titles. It only checks GetAsyncKeyState for the specific native-drag shortcut key(s) you configure (and briefly while recording a custom shortcut in Settings), and makes zero network requests unless you turn on update checks.

SetupHow do I uninstall it?

Uninstall normally from Windows Settings → Apps → Installed apps → NubMouse, or run NubMouse.exe --uninstall. It cleanly removes the app, shortcut, startup entry, and settings (and restores your ELAN driver's Scrolling setting if it switched it).
