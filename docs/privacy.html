Privacy Policy

Last updated: 2026

Short version: NubMouse does not collect, store, transmit, or share any personal data, usage analytics, or telemetry.

1. Input handling

NubMouse processes mouse movement, wheel, and middle-button events locally in memory solely to provide TrackPoint and pointing-stick scrolling, middle-click, and optional 3D/CAD drag shortcuts.

  • NubMouse never installs a keyboard hook.
  • NubMouse never logs keystrokes or window titles.
  • It only checks GetAsyncKeyState locally for the specific drag shortcut key(s) you configure (and briefly while recording a custom shortcut in Settings).

2. Local settings & optional debug logs

Your preferences (scroll speed, axis lock, per-device modes, and profiles) are stored locally on your PC under HKEY_CURRENT_USER\Software\NubMouse (or in a local NubMouse.ini file in portable mode).

If you explicitly turn on the optional debug log for troubleshooting, it writes mouse-event diagnostics locally to %TEMP%\NubMouse-debug.log and is never uploaded anywhere automatically.

3. Network access

  • Microsoft Store build: Makes zero network requests (updates are handled by the Microsoft Store).
  • Standalone GitHub build: Makes no network requests unless you explicitly enable automatic update checks or click Check for updates now, which only contacts GitHub to check and download releases.

4. Open source & contact

NubMouse is free and open source under the MIT License. You can inspect the complete source code at github.com/dstarikov/NubMouse. For privacy questions or support, please open an issue at github.com/dstarikov/NubMouse/issues.
